##  What Does This System Do?

This is a desktop application that helps HR managers track employee performance. Instead of drowning in Excel sheets, it provides a modern dashboard to:

1.  **Calculate Performance:** Uses a custom weighted algorithm `(Efficiency * Speed + Success) / 2` to determine a fair score.
2.  **Visualize Trends:** Compares an employee's history against the company average using dynamic charts.
3.  **Ensure Privacy:** Includes a strict **"Right to be Forgotten"** protocol (GDPR compliance) with secure deletion confirmations.
4.  **Report Instantly:** Generates professional, single-page PDF reports with embedded analytics charts.

---

##  The Tech Stack (Under the Hood)

I chose **Python** for its power in data science and flexibility in GUI development.

* **GUI:** `CustomTkinter` (Because standard Tkinter looks too 90s. I wanted a modern Dark Mode aesthetic).
* **Data Vis:** `Matplotlib` & `Seaborn` (For financial-grade plotting).
* **Reporting:** `FPDF` (Engineered to produce single-page, non-breaking executive summaries).
* **Database:** CSV-based CRUD system (Lightweight and portable).
